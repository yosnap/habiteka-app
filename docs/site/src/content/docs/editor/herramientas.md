## Vistas y selección

| Control | Para qué sirve |
|---|---|
| Plano técnico | Revisar trazado y dimensiones. |
| Plano visual | Trabajar con la representación visual del plano. |
| 3D | Revisar volumen, acabados y circulación. |
| Seleccionar | Seleccionar elementos o arrastrar un marco de selección. |
| Propiedades | Cambiar parámetros del elemento seleccionado. |
| Medir | Comprobar distancias. |
| Texto | Añadir etiquetas al plano. |

## Construir

Abre **Construir** para paredes, habitaciones, puertas, ventanas y huecos; también columnas, escaleras, rampas y otras formas disponibles. Los huecos se vinculan a una pared.

Para cadenas de paredes, pulsa para fijar inicio y extremos. Cerrar el contorno termina la cadena; Escape termina un trazo abierto conservando los tramos confirmados. Una habitación rectangular se dibuja arrastrando sus esquinas.

Con ajuste activo, las guías ayudan a unir extremos y cerrar recintos. Comprueba las uniones en el plano técnico.

## Amueblar y propiedades

Abre **Amueblar**, elige el objeto y colócalo. En **Propiedades**, revisa dimensiones, giro, elevación y acabados disponibles.

Los tiradores de esquina cambian el tamaño manteniendo la esquina opuesta. Alt permite crecer alrededor del centro. Las medidas de controles espaciales se muestran en centímetros y los ángulos en grados; elevación cambia la posición vertical, no el tamaño.

## Suelos, paredes y exterior

- Selecciona un suelo para cambiar acabado, textura y parámetros disponibles.
- Selecciona una pared y utiliza **Pintar** para elegir su cara interior o exterior.
- **Construir → Patio / terraza** permite superficies exteriores abiertas.
- **Construir → Exterior y jardín** agrupa vegetación, cerramientos, pérgolas y equipamiento.
- **Terreno** y **Pavimento** añaden superficies exteriores con distinta finalidad; un pavimento visual no habilita por sí mismo un recorrido.

## Plantas, techos y recorrido

Gestiona niveles desde el selector de planta. Configura [Techos y luces](/editor/techos-luces-tejado/) por estancia. **Recorrido** permite preparar la ruta que podrá exportarse desde la versión aprobada.

## Navegación 3D

Utiliza los botones de acercar, alejar y encuadrar; el selector **Vistas** cambia la cámara. **Entrar en una estancia** coloca la cámara a altura de ojos. La vista de maqueta y los controles de techo facilitan examinar el interior: ocultar una cubierta para estudiar el plano no la elimina del diseño.

Consulta [Atajos](/editor/atajos/) para trabajar con teclado.
