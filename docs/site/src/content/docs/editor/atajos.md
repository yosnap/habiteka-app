---
title: Navegación y atajos
description: Referencia de teclado y gestos del editor.
---

Los atajos de letra actúan con el foco fuera de un campo de texto. Puedes desactivarlos en el menú de visibilidad del editor.

## Herramientas

| Tecla | Acción |
|---|---|
| S | Seleccionar |
| C | Abrir o cerrar Construir |
| F | Abrir Amueblar |
| B | Dibujar paredes |
| R | Dibujar habitación rectangular |
| D | Colocar puerta |
| V | Colocar ventana |
| H | Colocar hueco |
| M | Medir |
| A | Activar o desactivar ajuste |

## Vista y edición

| Tecla o gesto | Acción |
|---|---|
| Espacio | Activar o desactivar Mano |
| 0 | Encuadrar el plano |
| + / − | Acercar / alejar |
| Rueda | Zoom del plano sobre el puntero |
| ⌘/Ctrl + Z | Deshacer |
| Mayús + ⌘/Ctrl + Z | Rehacer |
| ⌘/Ctrl + C | Copiar una selección espacial |
| ⌘/Ctrl + V | Iniciar colocación de la copia |
| ⌘/Ctrl + A | Seleccionar todo |
| Supr / Retroceso | Eliminar la selección |
| Flechas | Mover la selección 1 cm |
| Mayús + flechas | Mover la selección 10 cm |
| Escape | Cancelar trazo, deseleccionar o cerrar paneles del editor |

En macOS utiliza ⌘; en otros sistemas, Ctrl para los comandos de edición.

## Selección y dimensiones

| Gesto | Acción |
|---|---|
| Arrastrar en espacio libre | Marco de selección |
| Mayús/⌘ al seleccionar | Sumar elementos a la selección |
| Alt/⌥ al seleccionar | Restar elementos a la selección |
| Arrastrar tirador de esquina | Redimensionar manteniendo la esquina opuesta |
| Alt al redimensionar | Redimensionar alrededor del centro |

## Controles de parcela

Los sliders y botones −/+ ajustan zoom, escala, giros y dimensiones. Escribe una medida exacta y pulsa Enter o sal del campo para aplicarla. Los controles de zoom de parcela son independientes de los del lienzo del editor.

## Buscar en esta documentación

Utiliza el buscador superior o ⌘/Ctrl + K. Es un atajo del sitio de documentación, no una herramienta de dibujo.
